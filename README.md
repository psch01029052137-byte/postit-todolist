# Post-it Todo List

포스트잇 감성의 직관적이고 미려한 투두리스트 웹 애플리케이션입니다.  
구글 스프레드시트와 실시간 연동되어 메모의 생성, 수정, 삭제, 완료, 순서 변경(CRUD)을 안전하게 관리할 수 있습니다.

---

## 🌟 주요 기능

1. **포스트잇 입력 및 출력**
   - 메인 화면 중앙에서 범주(할 일, 아이디어, 기타)와 메모 내용을 입력하여 등록.
   - 실제 포스트잇처럼 테이프 및 그림자 질감, 자연스러운 각도 적용.
   - 노란색, 분홍색, 초록색, 파랑색 중 무작위 색상 자동 지정.
2. **착 하고 붙는 스냅 애니메이션**
   - 메모 추가 시 쫀득하게 화면에 착 달라붙는 탄성 키프레임 애니메이션 적용.
3. **한 행에 메모 4개 배치 & 반응형 디자인**
   - 데스크톱 화면에서 한 행에 4개씩 균형감 있게 배치.
   - 태블릿(2~3개), 모바일(1개) 화면에 맞춘 최적화된 반응형 그리드.
4. **작성 일시 표시**
   - 각 메모의 왼쪽 하단에 `연월일 시간 요일`이 작고 흐릿한 글씨로 표시 (예: `2026.10.15 (목) 15:36`).
5. **라이트 / 다크 모드 지원**
   - 상단 토글 버튼을 통해 라이트 모드(기본)와 다크 모드를 손쉽게 전환.
   - 다크 모드에서도 포스트잇의 색상 대비와 가독성을 고려한 전용 팔레트 적용.
6. **카테고리 필터링 드롭다운**
   - 전체 보기, 할 일, 아이디어, 기타 드롭다운으로 원하는 범주만 빠르게 확인.
7. **드래그 앤 드롭 (모바일 터치 완벽 지원)**
   - 데스크톱 마우스 및 모바일 스마트폰 터치 제스처로 메모 카드를 자유롭게 끌어서 순서 변경 가능 (SortableJS 연동).
8. **메모 카드 액션**
   - **체크 버튼**: 완료 상태 토글 (취소선 표시 및 구글 시트에 '체크' 반영).
   - **편집 버튼**: 모달 창이 열려 카테고리와 메모 내용을 즉시 수정.
   - **삭제 버튼**: 확인 없이 즉시 포스트잇을 떼어내어 삭제.
9. **Footer 영역**
   - `Copyright INU Post-it Todo List by OOO` 문구 포함.

## 📊 구글 시트(Google Sheets) 열 구조

구글 시트의 7개 열과 정확하게 1:1 매핑되어 작동합니다:

| 열 | 헤더 제목 | 설명 | 데이터 타입 |
|:---:|:---|:---|:---|
| **A열** | `timestamp` | 시트 기록 날짜 및 시간 | 날짜/시간 (예: `2026-10-15 15:36:00`) |
| **B열** | `datetime` | 메모 생성 날짜 및 시간 (고유 식별자) | 날짜/시간 (예: `2026.10.15 (목) 15:36`) |
| **C열** | `category` | 메모 범주 | 문자열 (`할 일`, `아이디어`, `기타`) |
| **D열** | `content` | 메모 내용 | 문자열 |
| **E열** | `color` | 메모 색상 | 숫자 (`1`: 노랑, `2`: 분홍, `3`: 초록, `4`: 파랑) |
| **F열** | `state` | 완료 상태 | 문자열 (`체크` 또는 `미완료`) |
| **G열** | `order` | 메모 표시 순서 | 정수 (`1`, `2`, `3` ...) |

## 🚀 구글 시트 연동 가이드 (3분 완성)

1. [Google 스프레드시트](https://sheets.new)를 새로 생성합니다. (시트 이름 자유 지정)
2. 상단 메뉴에서 **[확장 프로그램]** > **[Apps Script]**를 클릭합니다.
3. 프로젝트 내 기본 코드를 모두 지우고, 본 저장소의 **`Code.gs`** 파일 내용을 그대로 붙여넣습니다.
4. 우측 상단의 **[배포]** > **[새 배포]** 버튼을 클릭합니다.
5. 톱니바퀴 아이콘을 눌러 유형을 **"웹 앱"**으로 선택합니다.
6. 아래와 같이 설정합니다:
   - **설명**: `Post-it API`
   - **다음 사용자로 실행**: `나(자신의 구글 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`** ★필수★
7. **[배포]**를 누르고, 구글 권한 승인 창이 뜨면 **[액세스 승인]**을 진행합니다.
8. 발급된 **"웹 앱 URL"** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.
9. `index.html`을 브라우저로 열고 우측 상단의 **[시트 연동]** 버튼을 눌러 복사한 URL을 입력하고 **[설정 저장]** 또는 **[연결 테스트]**를 누르면 즉시 동기화가 완료됩니다!
