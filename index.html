구글 시트 연동 설정

구글 스프레드시트의 Google Apps Script 웹 앱 URL을 등록하면 모든 메모의 생성, 수정, 삭제, 완료 체크가 실시간으로 구글 시트에 기록됩니다.

※ 배포 시 '액세스 권한: 모든 사용자(Anyone)'로 배포해야 합니다.

구글 시트 열 구조 (7개 열 자동 인식):

  1. A열 (timestamp): 시트기록날짜및시간
  2. B열 (datetime): 메모생성날짜및시간 (고유키)
  3. C열 (category): 메모범주
  4. D열 (content): 메모내용
  5. E열 (color): 메모색상 (1:노랑, 2:분홍, 3:초록, 4:파랑)
  6. F열 (state): 완료 상태 ('체크' 또는 '미완료')
  7. G열 (order): 메모 순서 (숫자)
